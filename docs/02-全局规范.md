# TidePlay / DIMBOX 全局规范

> 本文档是后端所有服务的统一约束，`common` 模块的代码即本文档的落地实现。
> 冻结原则：这里的约定一旦被多服务引用，改动需走评审，避免各服务各写一套。

## 4. 统一响应结构

所有接口返回 `Result<T>`，HTTP 状态码与响应体 `code` 保持一致：成功 `200`，错误 `4xx/5xx`：

```json
{
  "code": 200,
  "message": "成功",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 与 HTTP 状态码一致，200 成功，4xx/5xx 失败 |
| message | string | 提示信息，可直接展示给用户 |
| data | T | 业务数据，可为空 |

## 5. 错误码规范

遵循 HTTP 语义：`200=成功`，`4xx=客户端错误`，`5xx=服务端错误`。业务错误复用标准 HTTP 状态码，用 `message` 区分具体含义。

| 错误码 | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数/业务校验错误 |
| 401 | 未登录或登录已过期 |
| 403 | 无权限访问 |
| 404 | 资源不存在 |
| 405 | 请求方式不支持 |
| 409 | 资源冲突 |
| 429 | 请求过于频繁 |
| 500 | 系统繁忙，请稍后重试 |

## 6. 统一异常处理

- 业务校验失败抛 `BizException`，由全局 `GlobalExceptionHandler` 转为 `Result` 并设置对应 HTTP 状态码。
- 参数校验使用 `@Valid`，校验失败返回 `400`。
- 禁止在 Controller 里 `try-catch` 业务异常后手工拼返回；统一走异常体系。

## 7. 鉴权规范

- 登录成功后签发 JWT，前端放在请求头：`Authorization: Bearer <token>`。
- 网关统一校验 token 并透传用户身份（`X-User-Id` 等），下游服务不再重复解析 token。
- 白名单路径（登录、注册、商品浏览等）在网关配置，不进鉴权过滤器。

## 8. 全局数据约定

| 项 | 约定 |
|---|---|
| 金额 | 统一用「分」的整数存储，避免浮点误差 |
| 时间 | 数据库 `DATETIME`，接口返回 `yyyy-MM-dd HH:mm:ss` 字符串 |
| 分页 | 请求 `pageNum`/`pageSize`（默认 1/10），返回 `total`/`records` |
| 主键 | 分布式 ID（雪花算法），不使用数据库自增对外暴露 |
| 逻辑删除 | 用 `deleted` 标记，不做物理删除 |
| 审计字段 | 统一 `created_at` / `updated_at` |

## 9. 数据库命名与核心 ER

- 表名：`t_` 前缀 + 小写下划线，如 `t_user`。
- 字段：小写下划线，如 `created_at`。
- 索引：`idx_表名_字段`，唯一索引 `uk_表名_字段`。

核心表（首期）：

| 表 | 用途 | 关键字段 |
|---|---|---|
| t_user | 用户 | id, username, password, nickname, status |
| t_user_address | 收货地址 | id, user_id, receiver, phone, detail |
| t_category | 商品分类 | id, parent_id, name |
| t_product | 商品(SPU) | id, name, category_id, brand, price |
| t_product_sku | 商品规格(SKU) | id, product_id, spec, price |
| t_sku_stock | 库存 | sku_id, stock, locked_stock |
| t_order | 订单 | id, order_no, user_id, total_amount, status |
| t_order_item | 订单明细 | id, order_id, sku_id, quantity, price |

## 10. 包结构与组件扫描

- `common`：无 Web 依赖的纯 POJO / 工具，放 `com.dimbox.common`，所有服务可依赖。
- 各服务启动类设置 `@SpringBootApplication(scanBasePackages = "com.dimbox")`，以便扫描到 `common` 的组件。
- 注意：`common` 当前为承载全局异常处理器引入了 `spring-boot-starter-web`；后续接入 WebFlux 网关时，需把 Web 相关组件拆到 `common-web`，避免 servlet 与 webflux 冲突。
