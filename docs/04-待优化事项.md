## 后端优化 / 技术债

| 状态 | 事项 | 说明 |
| --- | --- | --- |
| 部分完成 | SKU 更新策略 | 已新增单品 SKU 管理接口（addSku/updateSku/updateSkuStatus/deleteSku），admin 可单独改款式；但商品整体 update 仍「删除旧 SKU 重建」，会重置 SKU id 与库存，需改成按 id 增量更新 |
| 待办 | 取消订单一致性 | order 取消当前为「先回补后改状态」，极端场景需补偿，后续用 MQ + 本地消息表做最终一致 |
| 已完成 | 角色权限隔离 | 已引入管理员角色：JWT 携带 role，网关 adminPaths 校验，普通用户访问管理端返回 403 |
| 待办 | 内部接口安全边界 | product 的 stock/deduct、restore、increase、sku/{id} 与 order/internal 等内部接口不经过网关、无 token 校验，依赖「服务端口不直接暴露公网」；真实部署时需服务间网络隔离或额外鉴权 |
| 待办 | 盲盒抽盒最终一致 | drawBlindbox 当前为「同步扣库存 + 本地写记录」，insert 失败用回补库存补偿；高并发下应改为 MQ 最终一致（扣库存成功发消息，异步落库 + 重试 + 死信兜底） |
