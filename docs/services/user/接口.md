# user 模块接口文档

## 通用约定

详见 [全局规范](../../02-全局规范.md)，关键点：

- 响应统一为 `{ code, message, data }`，`code=200` 成功。
- 所有接口经网关访问，前缀 `/api/user`，网关 `StripPrefix` 后对应本服务的 `/user`。
- 鉴权：`Authorization: Bearer <token>`，身份经请求头 `X-User-Id` 透传。
- 金额单位「分」、时间格式 `yyyy-MM-dd HH:mm:ss`、生日格式 `yyyy-MM-dd`。

## 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /user/profile | 查询资料 |
| PUT | /user/profile | 修改资料 |
| PUT | /user/password | 修改密码 |
| POST | /user/address | 新增地址 |
| GET | /user/address | 地址列表 |
| PUT | /user/address/{id} | 修改地址 |
| DELETE | /user/address/{id} | 删除地址 |
| PUT | /user/address/{id}/default | 设置默认地址 |
| GET | /user/admin/list | 用户列表（管理员） |
| PUT | /user/admin/{id}/status | 禁用/启用用户（管理员） |

## 1. 查询资料

```http
GET /api/user/profile
Authorization: Bearer <token>
```

响应：

```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "id": 1790000000000000000,
    "username": "test",
    "nickname": "测试用户",
    "avatar": "https://example.com/a.png",
    "gender": 1,
    "birthday": "2000-01-01",
    "bio": "你好",
    "phone": "13800138000",
    "email": "a@b.com"
  }
}
```

## 2. 修改资料

```http
PUT /api/user/profile
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "nickname": "新昵称",
  "avatar": "https://example.com/a.png",
  "gender": 1,
  "birthday": "2000-01-01",
  "bio": "你好"
}
```

字段约束：`nickname` ≤ 32，`bio` ≤ 255，`gender` ∈ {0,1,2}，`birthday` 为 `yyyy-MM-dd` 且不晚于当天，`avatar`/`birthday`/`bio` 可空。

响应：`{ "code": 200, "message": "成功", "data": null }`

## 3. 修改密码

```http
PUT /api/user/password
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "oldPassword": "123456",
  "newPassword": "654321"
}
```

约束：`newPassword` 6-20 位且不等于 `oldPassword`；`oldPassword` 校验失败返回 `400`。

响应：`{ "code": 200, "message": "成功", "data": null }`（成功后前端清除 token 重新登录）

## 4. 地址相关

地址对象：

```json
{
  "id": 1790000000000000001,
  "receiver": "张三",
  "phone": "13800138000",
  "province": "广东省",
  "city": "深圳市",
  "district": "南山区",
  "detail": "科技园 1 号",
  "isDefault": 1
}
```

### 4.1 新增地址

```http
POST /api/user/address
```

```json
{
  "receiver": "张三",
  "phone": "13800138000",
  "province": "广东省",
  "city": "深圳市",
  "district": "南山区",
  "detail": "科技园 1 号",
  "isDefault": 0
}
```

### 4.2 地址列表

```http
GET /api/user/address
```

响应 `data` 为地址对象数组，默认地址排前。

### 4.3 修改地址

```http
PUT /api/user/address/{id}
```

请求体同新增（不含 `id`），仅允许操作本人地址，否则返回 `403`。

### 4.4 删除地址

```http
DELETE /api/user/address/{id}
```

逻辑删除；若删除默认地址，自动将最新一条设为默认。

### 4.5 设置默认地址

```http
PUT /api/user/address/{id}/default
```

事务内取消原默认并设置新默认。

## 5. 用户管理（管理员）

### 5.1 用户列表

```http
GET /api/user/admin/list?username=test&status=1&pageNum=1&pageSize=10
Authorization: Bearer <token>
```

- 仅管理员可访问。
- 支持按用户名模糊、按状态筛选，按创建时间倒序。

响应 `data` 为 `PageResult`，`records` 每项：

```json
{
  "id": 1790000000000000000,
  "username": "test",
  "nickname": "测试用户",
  "phone": "13800138000",
  "role": 0,
  "status": 1,
  "createdAt": "2026-10-27 12:00:00"
}
```

### 5.2 禁用 / 启用用户

```http
PUT /api/user/admin/{id}/status
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{ "status": 0 }
```

- `status`：`1` 启用，`0` 禁用。
- 禁用后该用户登录被拒绝；管理员可恢复启用。

响应：`{ "code": 200, "message": "成功", "data": null }`

## 错误码

| 码 | 含义 |
|---|---|
| 400 | 旧密码错误 |
| 400 | 地址数量超限 |
| 403 | 无权操作该地址 |
| 404 | 地址不存在 |
