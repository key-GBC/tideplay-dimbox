# admin 前端设计文档

## 1. 概述

- 技术栈与 `web` 一致：Vue3 + Vite + Element Plus + Pinia + Vue Router + Axios。
- 目标：为运营侧提供商品、秒杀活动、订单、用户的管理界面。
- 布局：标准「侧边栏 + 顶栏 + 内容区」，主力组件 `el-table` + `el-dialog` + `el-form`。

## 2. 前置依赖

当前 `user` 的登录响应 `LoginResponse` 不含 `role`，admin 登录后无法判断是否管理员。开发前需在后端补一个字段：

```json
{ "token": "...", "userId": 1, "username": "admin", "role": 1 }
```

> 改动点：`user` 的 `LoginResponse` 增加 `role`，登录时随用户信息返回。前端据此决定是否放行进入后台。

## 3. 页面与路由

| 路由 | 页面 | 说明 |
|---|---|---|
| /login | Login | 管理员登录（校验 role=1） |
| /dashboard | Dashboard | 概览（可选，首期可省） |
| /product/category | CategoryManage | 分类增删改查 |
| /product/brand | BrandManage | 品牌增删改查 |
| /product | ProductManage | 商品列表/新增/编辑/上下架 |
| /seckill/activity | SeckillActivityManage | 秒杀活动管理 + 预热 |
| /order | OrderManage | 全部订单列表 |
| /user | UserManage | 用户列表 + 禁用/启用 |

```text
├── stores/user.js          # 登录态 + role
├── layout/
│   └── AdminLayout.vue     # 侧边栏 + 顶栏 + 内容区
└── views/                  # 对应上表页面
```

## 5. 鉴权与路由守卫

- 登录后存 `token` + `role` 到 Pinia 与 localStorage。
- 路由守卫：未登录跳登录；已登录但 `role != 1` 提示「无管理员权限」并退出。
- 请求拦截器：401 登出跳登录；403 提示「无权限访问」。

## 6. 接口对接映射

| 页面 | 调用的接口 |
|---|---|
| Login | POST /api/user/login |
| CategoryManage | POST/GET/PUT/DELETE /api/product/category |
| BrandManage | POST/GET/PUT/DELETE /api/product/brand |
| ProductManage | POST /api/product、PUT /api/product/{id}、PUT /api/product/{id}/status、DELETE /api/product/{id}、GET /api/product/admin/{id}、SKU 增删改与上下架 |
| SeckillActivityManage | POST /api/promotion/seckill/activity、warmup |
| OrderManage | GET /api/order/admin/list |
| UserManage | GET /api/user/admin/list、PUT /api/user/admin/{id}/status |

## 7. 关键交互约定

- 金额展示「分 → 元」，时间按 `yyyy-MM-dd HH:mm:ss`。
- 商品新增/编辑：表单含 SKU 列表编辑（至少 1 个 SKU）。
- 商品列表支持展开行查看款式，款式可独立编辑、上下架、删除（最后一个款式不可删）。
- 秒杀活动创建后，需要调用「预热」把库存写入 Redis。
- 列表统一分页 + 搜索条件，操作类按钮做二次确认（删除、禁用）。
