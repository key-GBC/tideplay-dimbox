# web 前端设计文档

## 1. 概述

- 技术栈：Vue3 + Vite + Element Plus + Pinia + Vue Router + Axios（已在 `frontend/web` 落地）。
- 目标：把后端六个服务的购买链路串成浏览器里的完整用户端体验。
- 接口对接统一走 `src/api/request.js`（已有 axios 实例：自动带 token、统一处理 `Result` 与 401）。

## 2. 页面与路由

| 路由 | 页面 | 是否需登录 | 说明 |
|---|---|---|---|
| /login | Login | 否 | 登录/注册 |
| / | Home | 是 | 商品列表：分类、品牌、搜索、分页 |
| /product/:id | ProductDetail | 是 | 商品详情：SKU 选择、数量、立即购买 |
| /order/confirm | OrderConfirm | 是 | 确认订单：地址快照、提交下单 |
| /order | OrderList | 是 | 订单列表：状态筛选 |
| /order/:id | OrderDetail | 是 | 订单详情：明细、支付、取消 |
| /profile | Profile | 是 | 个人中心：资料 + 地址管理 |
| /payment/result | PaymentResult | 是 | 支付结果展示 |

## 3. 目录结构

```text
frontend/web/src
├── api/
│   ├── request.js          # axios 实例（已有）
│   ├── auth.js             # 登录/注册/当前用户（已有）
│   ├── product.js          # 分类/品牌/商品
│   ├── order.js            # 下单/列表/详情/取消
│   ├── payment.js          # 创建支付单/支付/查询
│   └── user.js             # 资料/改密/地址
├── router/index.js         # 路由 + 登录守卫（已有）
├── stores/
│   ├── user.js             # 登录态（已有）
│   └── cart.js             # P0 暂用「立即购买」传递，不做购物车
├── components/
│   ├── ProductCard.vue     # 商品卡片
│   ├── SkuSelector.vue     # SKU 选择器
│   └── AddressPicker.vue   # 地址选择
└── views/                  # 对应上表页面
```

## 4. 状态管理

- `user` store：`token` + `userInfo`，持久化到 localStorage（已有）。
- `cart` store：P0 不做购物车，用「立即购买」直接携带 `skuId + quantity` 跳转确认页，后续再接购物车。

## 5. 接口对接映射

| 页面 | 调用的接口 |
|---|---|
| Login | POST /api/user/login、/api/user/register |
| Home | GET /api/product/category/tree、/brand/list、/list |
| ProductDetail | GET /api/product/{id} |
| OrderConfirm | POST /api/order（含地址快照 + requestId） |
| OrderList | GET /api/order?status=... |
| OrderDetail | GET /api/order/{id}、POST /api/order/{id}/cancel |
| Profile | GET/PUT /api/user/profile、/password、/address CRUD |
| 支付 | POST /api/payment/create、/{paymentNo}/pay、GET /{paymentNo} |

## 6. 关键交互约定

- 下单 `requestId` 用前端生成的 UUID，保证幂等。
- 金额展示由「分」转为「元」，前端不参与金额计算。
- 商品列表的 `price` 为 SKU 最低价，详情页以选中 SKU 的 `price` 为准。
- 401 时统一由 `request.js` 拦截器登出并跳转登录页。
