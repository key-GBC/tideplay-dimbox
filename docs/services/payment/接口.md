# payment 模块接口文档

## 通用约定

- 响应统一 `{ code, message, data }`，`code` 与 HTTP 状态码一致，成功 `200`。
- 金额单位「分」；时间 `yyyy-MM-dd HH:mm:ss`。
- 接口经网关 `/api/payment`，需登录，身份经 `X-User-Id` 透传。

## 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /payment/create | 创建支付单 |
| POST | /payment/{paymentNo}/pay | mock 支付（模拟支付成功） |
| POST | /payment/callback | 支付回调（幂等） |
| GET | /payment/{paymentNo} | 查询支付单 |

## 1. 创建支付单

```http
POST /api/payment/create
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{ "orderNo": "20261102..." }
```

响应 `data`：

```json
{
  "paymentNo": "P20261102...",
  "amount": 13800,
  "status": 10
}
```

重复创建返回原支付单，不报错。

## 2. mock 支付

```http
POST /api/payment/{paymentNo}/pay
```

模拟用户完成支付，内部走与真实回调一致的处理逻辑。

响应：`{ "code": 200, "message": "成功", "data": null }`

## 3. 支付回调

```http
POST /api/payment/callback
Content-Type: application/json
```

```json
{ "paymentNo": "P20261102...", "channel": "mock" }
```

- 幂等：重复回调直接返回成功。
- 成功后支付单与订单均变为「已支付」。

## 4. 查询支付单

```http
GET /api/payment/{paymentNo}
```

响应 `data`：

```json
{
  "paymentNo": "P20261102...",
  "orderNo": "20261102...",
  "amount": 13800,
  "channel": "mock",
  "status": 20,
  "paidAt": "2026-11-02 12:00:00"
}
```

## 错误码

| 码 | 含义 |
|---|---|
| 400 | 参数错误 |
| 403 | 无权操作该支付单 |
| 404 | 支付单不存在 / 订单不存在 |
| 409 | 订单状态不允许支付 |
