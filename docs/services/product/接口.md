# product 模块接口文档

## 通用约定

- 响应统一 `{ code, message, data }`，`code` 与 HTTP 状态码一致，成功 `200`。
- 价格一律「分」；时间 `yyyy-MM-dd HH:mm:ss`。
- 用户端浏览接口（分类树、品牌列表、商品列表/详情）**无需登录**，需加入网关白名单。
- 后台管理接口需登录；库存扣减为内部接口，后续 `order` 经 Feign 调用。

## 接口清单

### 用户端（公开）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /product/category/tree | 分类树 |
| GET | /product/brand/list | 品牌列表 |
| GET | /product/list | 商品分页列表 |
| GET | /product/{id} | 商品详情（含 SKU） |

### 后台（需登录）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /product/category | 新增分类 |
| PUT | /product/category/{id} | 修改分类 |
| DELETE | /product/category/{id} | 删除分类 |
| POST | /product/brand | 新增品牌 |
| PUT | /product/brand/{id} | 修改品牌 |
| DELETE | /product/brand/{id} | 删除品牌 |
| POST | /product | 新增商品（含 SKU） |
| PUT | /product/{id} | 修改商品（含 SKU） |
| PUT | /product/{id}/status | 上下架 |
| DELETE | /product/{id} | 删除商品 |
| GET | /product/admin/{id} | 商品详情（管理员，含下架） |
| POST | /product/{id}/sku | 新增款式 |
| PUT | /product/sku/{skuId} | 修改款式 |
| PUT | /product/sku/{skuId}/status | 款式上下架 |
| DELETE | /product/sku/{skuId} | 删除款式 |

### 内部（库存）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /product/stock/deduct | 原子扣减库存 |

## 关键接口示例

### 商品分页列表

```http
GET /api/product/list?categoryId=1&brandId=2&keyword=盲盒&pageNum=1&pageSize=10
```

响应 `data`：

```json
{
  "total": 100,
  "records": [
    {
      "id": 1790000000000000100,
      "name": "某 IP 系列盲盒",
      "subTitle": "潮玩盲盒",
      "mainImage": "https://example.com/main.png",
      "price": 6900
    }
  ],
  "pageNum": 1,
  "pageSize": 10
}
```

> `price` 为该商品 SKU 最低价（分）。

### 商品详情

```http
GET /api/product/{id}
```

响应 `data`：

```json
{
  "id": 1790000000000000100,
  "name": "某 IP 系列盲盒",
  "subTitle": "潮玩盲盒",
  "mainImage": "https://example.com/main.png",
  "detail": "商品详情",
  "categoryId": 1,
  "brandId": 2,
  "skus": [
    { "id": 1, "skuName": "标准款", "image": "https://example.com/sku.png", "price": 6900, "stock": 100 }
  ]
}
```

### 新增商品（后台）

```http
POST /api/product
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "categoryId": 1,
  "brandId": 2,
  "name": "某 IP 系列盲盒",
  "subTitle": "潮玩盲盒",
  "mainImage": "https://example.com/main.png",
  "detail": "商品详情",
  "skus": [
    { "skuName": "标准款", "price": 6900, "stock": 100, "image": "https://example.com/sku.png" }
  ]
}
```

### 上下架

```http
PUT /api/product/{id}/status
```

```json
{ "status": 1 }
```

### 库存扣减（内部）

```http
POST /api/product/stock/deduct
```

```json
{ "skuId": 1, "quantity": 2 }
```

库存不足返回 `409`。

## 管理员商品详情与款式管理

### 管理员商品详情

```http
GET /api/product/admin/{id}
Authorization: Bearer <token>
```

- 与用户端详情结构一致，但不限制商品上下架状态，供后台查看/编辑下架商品。
- 返回的 `skus` 每项含 `id / skuName / image / price / stock / status`。

### 新增款式

```http
POST /api/product/{id}/sku
```

```json
{ "skuName": "隐藏款", "image": "https://example.com/sku.png", "price": 9900, "stock": 10 }
```

### 修改款式

```http
PUT /api/product/sku/{skuId}
```

请求体同新增款式，可修改名称、图片、价格、库存。

### 款式上下架

```http
PUT /api/product/sku/{skuId}/status
```

```json
{ "status": 0 }
```

款式状态独立于商品：商品上架但某款式下架时，该款式不展示。

### 删除款式

```http
DELETE /api/product/sku/{skuId}
```

- 逻辑删除。
- 商品至少保留 1 个款式，最后一个款式不可删除，返回 `409`。

## 错误码

| 码 | 含义 |
|---|---|
| 400 | 参数/业务校验错误 |
| 404 | 分类/品牌/商品/SKU 不存在 |
| 409 | 分类下存在子分类 / 库存不足 |
