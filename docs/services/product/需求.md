# product 模块需求文档

## 1. 背景与目标

`product` 是下单链路的商品侧前置依赖。本期目标：建立分类、品牌、商品（SPU/SKU）与库存的数据模型和管理/浏览能力，为后续 `order` 下单与「盲盒/秒杀」提供商品与库存基础。

## 2. 用户与场景

- 普通用户：浏览分类、品牌、商品列表与详情（含 SKU、价格、库存）。
- 运营/后台：维护分类、品牌、商品与 SKU，控制上下架。

## 3. 功能范围

### 本期 P0

| 编号 | 功能 | 说明 |
|---|---|---|
| P-01 | 分类管理 | 多级分类，树形展示，增删改查 |
| P-02 | 品牌管理 | 品牌/IP/设计师，增删改查 |
| P-03 | 商品 SPU | 创建/修改/上下架/删除，列表与详情 |
| P-04 | 商品 SKU | 随商品维护规格/款式、价格、库存 |
| P-05 | 库存扣减 | 原子扣减接口，为下单预留 |

### 后续（不在本期）

- 商品搜索（ES）、评价、盲盒概率配置、收藏、销量统计。

## 4. 功能详述

### P-01 分类

- 多级分类，用 `parent_id` 表达层级，`parent_id=0` 为顶级。
- 树形查询返回完整分类树。
- 删除校验：分类下存在子分类时不允许删除（返回 409）。

### P-02 品牌

- 字段：名称、Logo、描述、状态。
- 平铺列表，支持按状态过滤。

### P-03 / P-04 商品与 SKU

- 商品（SPU）字段：名称、副标题、分类、品牌、主图、详情、状态（上架/下架）。
- SKU 字段：款式名、图片、价格（分）、库存。
- 一个商品至少 1 个 SKU。
- 用户端列表/详情只返回「上架」商品；下架商品不可见。
- 上下架通过 `status` 字段控制。

### P-05 库存扣减

- 入参：`skuId` + `quantity`。
- 原子扣减：`stock - quantity`，且 `stock >= quantity`，否则返回库存不足。
- 该接口供后续 `order` 模块通过 Feign 调用，不面向前端。

## 5. 非功能需求

- 价格一律用「分」的整数存储与传输。
- 库存扣减必须原子，避免超卖。
- 用户端浏览接口无需登录；后台管理接口需登录（角色校验后续补）。

## 6. 验收标准

- 分类树、品牌、商品列表/详情能正常返回。
- 商品含 SKU，SKU 价格/库存正确。
- 下架商品对用户端不可见。
- 库存扣减并发下不会超卖，库存不足返回 409。
