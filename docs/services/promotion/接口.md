# promotion 模块接口文档

## 通用约定

- 响应统一 `{ code, message, data }`，`code` 与 HTTP 状态码一致，成功 `200`。
- 金额单位「分」；时间 `yyyy-MM-dd HH:mm:ss`。
- 用户端抢购/查询经网关 `/api/promotion`，需登录；后台活动管理同样需登录（角色隔离后续接入）。
- 秒杀库存与普通商品库存相互独立。

## 接口清单

### 后台（活动管理）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /promotion/seckill/activity | 创建秒杀活动 |
| GET | /promotion/seckill/activity | 活动分页列表 |
| POST | /promotion/seckill/activity/{id}/warmup | 预热库存到 Redis |

### 用户端（抢购与查询）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /promotion/seckill/{activityId}/buy | 秒杀抢购 |
| GET | /promotion/seckill/record | 我的秒杀记录 |

## 1. 创建秒杀活动

```http
POST /api/promotion/seckill/activity
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "skuId": 1001,
  "seckillPrice": 3900,
  "stock": 100,
  "startTime": "2026-11-10 10:00:00",
  "endTime": "2026-11-10 12:00:00"
}
```

响应 `data` 返回活动 id。

## 2. 秒杀抢购

```http
POST /api/promotion/seckill/{activityId}/buy
Authorization: Bearer <token>
```

响应 `data`：

```json
{ "orderNo": "20261110..." }
```

错误：

- 已抢购 → `409`
- 库存不足 → `409`
- 活动未开始或已结束 → `409`
- 触发限流 → `429`

## 3. 我的秒杀记录

```http
GET /api/promotion/seckill/record?pageNum=1&pageSize=10
```

响应 `data` 为 `PageResult`，每条记录含活动 id、SKU、订单号、状态、创建时间。

## 错误码

| 码 | 含义 |
|---|---|
| 400 | 参数错误 |
| 404 | 活动不存在 |
| 409 | 已抢购 / 库存不足 / 活动未开始或已结束 |
| 429 | 请求过于频繁（Sentinel 限流） |
