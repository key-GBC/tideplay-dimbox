# order 模块接口文档

## 通用约定

- 响应统一 `{ code, message, data }`，`code` 与 HTTP 状态码一致，成功 `200`。
- 金额单位「分」；时间 `yyyy-MM-dd HH:mm:ss`。
- 所有接口经网关 `/api/order`，需登录，身份经 `X-User-Id` 透传。

## 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /order | 提交订单 |
| GET | /order | 订单列表 |
| GET | /order/{id} | 订单详情 |
| POST | /order/{id}/cancel | 取消订单 |
| GET | /order/admin/list | 订单列表（管理员） |

## 1. 提交订单

```http
POST /api/order
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "requestId": "a1b2c3d4-...",
  "skuId": 1001,
  "quantity": 2,
  "address": {
    "receiver": "张三",
    "phone": "13800138000",
    "province": "广东省",
    "city": "深圳市",
    "district": "南山区",
    "detail": "科技园 1 号"
  },
  "remark": "尽快发货"
}
```

> `addressId` 不传，直接快照 `address` 对象，避免下单链路依赖 user 实时查询。

响应 `data`：

```json
{
  "orderNo": "20261027..."
}
```

错误：

- 库存不足 → `409`
- 重复 `requestId` → 返回原订单，不重复扣库存

## 2. 订单列表

```http
GET /api/order?status=10&pageNum=1&pageSize=10
```

响应 `data` 为 `PageResult`，`records` 每项：

```json
{
  "id": 1790000000000000200,
  "orderNo": "20261027...",
  "status": 10,
  "totalAmount": 13800,
  "createdAt": "2026-10-27 12:00:00"
}
```

## 4. 取消订单

```http
POST /api/order/{id}/cancel
```

- 仅「待支付」可取消，取消后回补库存，状态置为 `50`。
- 非本人订单返回 `403`；状态不允许返回 `409`。

响应：`{ "code": 200, "message": "成功", "data": null }`

## 5. 订单列表（管理员）

```http
GET /api/order/admin/list?status=10&orderNo=xxx&pageNum=1&pageSize=10
Authorization: Bearer <token>
```

- 仅管理员可访问，网关按 `adminPaths` 校验 `X-User-Role=1`。
- 查询全部用户订单，支持按状态、订单号筛选，按创建时间倒序。

响应 `data` 为 `PageResult`，`records` 每项：

```json
{
  "id": 1790000000000000200,
  "orderNo": "20261027...",
  "userId": 1790000000000000001,
  "status": 10,
  "totalAmount": 13800,
  "createdAt": "2026-10-27 12:00:00"
}
```

## 错误码

| 码 | 含义 |
|---|---|
| 400 | 参数错误 |
| 403 | 无权操作该订单 |
| 404 | 订单不存在 / 商品或 SKU 不存在 |
| 409 | 库存不足 / 订单状态不允许该操作 |
