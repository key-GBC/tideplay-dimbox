# 盲盒抽盒 前端设计文档

## 1. 概述

- 用户端 `web` 与管理端 `admin` 都要新增盲盒功能，复用各自已有的 Vue3 + Element Plus + Pinia + Router + Axios 技术栈与 `request` 封装。
- 用户端重点在「抽盒体验」，管理端重点在「系列/款式与概率配置」。

## 2. 后端前置依赖（需补充）

当前盲盒后端缺两个列表接口，前端开发前需要补：

| 接口 | 用途 | 说明 |
| --- | --- | --- |
| GET /api/promotion/blindbox/series/list | 用户端系列列表 | 分页，只返回启用系列 |
| GET /api/promotion/blindbox/admin/series/list | 管理端系列列表 | 含禁用系列，管理员视角 |

> 现有接口已覆盖：系列详情、单抽、抽盒记录（用户端），系列/款式的增删改（管理端）。

## 3. 用户端（web）

### 3.1 页面与路由

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| /blindbox | BlindBoxList | 盲盒系列列表（入口） |
| /blindbox/:id | BlindBoxDetail | 系列详情 + 单抽交互 |
| /blindbox/record | BlindBoxRecord | 我的抽盒记录 |

首页顶栏增加「盲盒」导航入口。

### 3.2 关键交互

- 抽盒：点击「抽一次」→ 调用单抽接口 → 展示抽中款式，隐藏款做彩蛋/高亮提示。
- 概率与隐藏款配置不对用户暴露，详情页只展示款式名与图片。

### 3.3 接口对接

| 页面 | 接口 |
| --- | --- |
| BlindBoxList | GET /api/promotion/blindbox/series/list |
| BlindBoxDetail | GET /api/promotion/blindbox/series/{id}、POST /api/promotion/blindbox/{seriesId}/draw |
| BlindBoxRecord | GET /api/promotion/blindbox/record |

## 4. 管理端（admin）

### 4.1 页面与路由

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| /blindbox | BlindBoxManage | 系列列表 + 新增/编辑 |
| /blindbox/:id/item | BlindBoxItemManage | 款式管理（概率、隐藏款、关联 SKU） |

### 4.2 接口对接

| 页面 | 接口 |
| --- | --- |
| BlindBoxManage | GET /api/promotion/blindbox/admin/series/list、POST/PUT /api/promotion/blindbox/series |
| BlindBoxItemManage | POST /api/promotion/blindbox/series/{id}/item、PUT/DELETE /api/promotion/blindbox/item/{itemId} |

## 5. 关键约定

- 概率只在管理端展示与配置，单位「万分比」，一个系列概率和 = 10000。
- 金额「分 → 元」展示。
- 抽盒动画与隐藏款提示属于前端交互，后端已通过 `isHidden` 字段返回。
- 管理端接口走管理员 token，越权由网关 `adminPaths` 统一拦截。
