# 盲盒抽盒 联调指南

> 目标：走通「管理员建系列/款式 → 用户单抽 → 记录落库 → 库存扣减」的完整链路。

## 前置准备

1. 已建表：`t_blindbox_series`、`t_blindbox_item`、`t_blindbox_order`。
2. 启动服务：`gateway`(8080)、`promotion`(8084)、`product`(8082)、`user`(8081)，并在 Nacos 确认都在线。
3. 准备管理员账号：`t_user` 中 `role = 1` 的账号（例如 `admin`）。
4. 准备一个商品 SKU：盲盒款式要关联 `sku_id`，先在 product 里有一个 SKU，记下它的 `skuId`。

> 网关地址统一为 `http://localhost:8080`，盲盒接口前缀 `/api/promotion`。

## 步骤 1：管理员登录

```http
POST http://localhost:8080/api/user/login
Content-Type: application/json
```

```json
{ "username": "admin", "password": "你的管理员密码" }
```

响应 `data` 中取出 `token`（记为 `adminToken`），并确认 `role` 为 `1`：

```json
{ "code": 200, "data": { "token": "eyJ...", "role": 1, "username": "admin" } }
```

## 步骤 2：创建盲盒系列

```http
POST http://localhost:8080/api/promotion/blindbox/series
Authorization: Bearer <adminToken>
Content-Type: application/json
```

```json
{
  "name": "测试系列",
  "description": "潮玩盲盒",
  "coverImage": "https://example.com/cover.png",
  "price": 5900
}
```

响应 `data` 返回系列 id，记为 `seriesId`。

## 步骤 3：创建款式（概率和凑到 10000）

```http
POST http://localhost:8080/api/promotion/blindbox/series/{seriesId}/item
Authorization: Bearer <adminToken>
Content-Type: application/json
```

```json
{
  "skuId": 1001,
  "styleName": "标准款 A",
  "image": "https://example.com/a.png",
  "probability": 5000,
  "isHidden": 0
}
```

再创建一个概率 `5000` 的款式（或按需凑满 10000）。例如再发一次，`probability` 填 5000、`styleName` 换一个。

> 概率校验：该系列所有款式概率之和不能超过 10000，否则创建/修改返回 `409`。

## 步骤 4：普通用户登录

```http
POST http://localhost:8080/api/user/login
Content-Type: application/json
```

```json
{ "username": "test", "password": "123456" }
```

响应 `data.token` 记为 `userToken`。

## 步骤 5：单抽

```http
POST http://localhost:8080/api/promotion/blindbox/{seriesId}/draw
Authorization: Bearer <userToken>
```

预期响应 `data`：

```json
{
  "orderNo": "1790000000000000000",
  "styleName": "标准款 A",
  "image": "https://example.com/a.png",
  "isHidden": 0
}
```

## 步骤 6：查抽盒记录

```http
GET http://localhost:8080/api/promotion/blindbox/record?pageNum=1&pageSize=10
Authorization: Bearer <userToken>
```

预期 `data.records` 里出现刚才抽中的记录（`orderNo`、`seriesId`、`skuId`、`isHidden`、`price`）。

## 步骤 7：验证库存扣减

在 MySQL 里查 SKU 库存：

```sql
SELECT id, sku_name, stock FROM t_product_sku WHERE id = 1001;
```

单抽前记录 `stock` 值，单抽后应减少 1。

## 异常场景验证

### 1. 库存不足

把某个 SKU 的库存改成 1，连续抽两次。第一次成功，第二次应返回：

```json
{ "code": 409, "message": "库存不足" }
```

### 2. 概率配置错误

让某个系列的款式概率总和不为 10000（例如只创建了一个概率 5000 的款式），单抽应返回：

```json
{ "code": 409, "message": "概率配置错误" }
```

### 3. 非管理员访问后台

用普通用户的 `userToken` 调后台接口：

```http
POST http://localhost:8080/api/promotion/blindbox/series
Authorization: Bearer <userToken>
```

应返回 `403`：

```json
{ "code": 403, "message": "无权限访问" }
```
