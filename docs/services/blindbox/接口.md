# 盲盒抽盒 接口文档

## 通用约定

- 响应统一 `{ code, message, data }`，`code` 与 HTTP 状态码一致，成功 `200`。
- 金额单位「分」；概率单位「万分比」。
- 用户端抽盒/记录经网关 `/api/promotion`，需登录；后台系列/款式管理需管理员。

## 接口清单

### 用户端

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /promotion/blindbox/series/{id} | 系列详情（含款式，不暴露概率） |
| POST | /promotion/blindbox/{seriesId}/draw | 单抽一次 |
| GET | /promotion/blindbox/record | 我的抽盒记录 |

### 后台（管理员）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /promotion/blindbox/series | 新增系列 |
| PUT | /promotion/blindbox/series/{id} | 修改系列 |
| POST | /promotion/blindbox/series/{id}/item | 新增款式 |
| PUT | /promotion/blindbox/item/{itemId} | 修改款式 |
| DELETE | /promotion/blindbox/item/{itemId} | 删除款式 |

## 1. 系列详情（用户端）

```http
GET /api/promotion/blindbox/series/{id}
```

响应 `data`：

```json
{
  "id": 1,
  "name": "某 IP 系列盲盒",
  "description": "潮玩盲盒",
  "coverImage": "https://example.com/cover.png",
  "price": 5900,
  "items": [
    { "id": 1, "styleName": "标准款 A", "image": "https://example.com/a.png" }
  ]
}
```

> 用户端不返回 `probability` 与 `is_hidden`，隐藏款与概率不对用户可见。

## 2. 单抽

```http
POST /api/promotion/blindbox/{seriesId}/draw
Authorization: Bearer <token>
```

响应 `data`：

```json
{
  "orderNo": "20261124...",
  "styleName": "标准款 A",
  "image": "https://example.com/a.png",
  "isHidden": 0
}
```

错误：库存不足 → `409`。

## 3. 我的抽盒记录

```http
GET /api/promotion/blindbox/record?pageNum=1&pageSize=10
```

响应 `data` 为 `PageResult`，每条含系列、款式、SKU、是否隐藏、价格、时间。

## 4. 新增系列（后台）

```http
POST /api/promotion/blindbox/series
Authorization: Bearer <token>
```

```json
{
  "name": "某 IP 系列盲盒",
  "description": "潮玩盲盒",
  "coverImage": "https://example.com/cover.png",
  "price": 5900
}
```

## 5. 新增款式（后台）

```http
POST /api/promotion/blindbox/series/{id}/item
```

```json
{
  "skuId": 1001,
  "styleName": "标准款 A",
  "image": "https://example.com/a.png",
  "probability": 2500,
  "isHidden": 0
}
```

> `probability` 为万分比，同一系列全部款式之和须为 10000。

## 错误码

| 码 | 含义 |
|---|---|
| 400 | 参数错误 |
| 404 | 系列/款式不存在 |
| 409 | 库存不足 / 概率总和不为 10000 |
