# 接口总览

> 本文档是所有后端接口的统一索引，供前端开发与联调使用。
> 详情仍以各模块 `docs/services/<模块>/接口.md` 为准，本文档只做快速检索。

## 通用约定

- 网关统一入口：`http://localhost:8080`，路由前缀 `/api`，网关 `StripPrefix=1` 后转发到对应服务。
- 响应统一 `{ code, message, data }`，`code` 与 HTTP 状态码一致，成功 `200`。
- 「公开」接口无需 token；「鉴权」接口需 `Authorization: Bearer <token>`，身份经 `X-User-Id` 透传。
- 「内部」接口为服务间 Feign 直连（`lb://服务名`），不经过网关、不加入白名单。
- 金额单位「分」；时间 `yyyy-MM-dd HH:mm:ss`。
